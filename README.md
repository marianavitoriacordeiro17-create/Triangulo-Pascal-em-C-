# Triangulo-Pascal-em-C-

Triangulo de Pascal em linguagem C, utilizando matrizes, condição, 
estrutura de repetição while e for, permitindo que o usuário digite a quantidade de linhas,
caso seja solicitado uma quantidade de linha menor que zero, uma mensagem é mostrada,
pedindo ao usuário que o numero seja válido (maior que zero).
